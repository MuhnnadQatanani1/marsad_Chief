# دليل نشر المشروع على Vercel (5 خطوات)

مشروع واجهة أمامية ثابتة (Static) بلا خادم ولا قاعدة بيانات. كل الملفات تُرفع كما هي من مجلد `pacc-dashboard`.

## الخطوة 1 — تجهيز المشروع محلياً
افتح المجلد `pacc-dashboard` في محرر النصوص، وتأكد من وجود:
- `index.html` + `login.html` + `chairman.html` + `deputy.html`
- مجلد `css/` و `js/` ومجلد `assets/` (صورة الشعار `pacc-logo.jpg`)
- `data.json` و `recommendations.json`
- `vercel.json`

يمكنك فتح `index.html` محلياً للاختبار، أو تشغيل أي خادم ثابت مثل:
```
npx serve .
```
ملاحظة: الدخول يستخدم `sessionStorage` ويجب فتح الصفحات عبر `http://` أو `https://` لا عبر `file://` المباشر.

## الخطوة 2 — إنشاء حساب Vercel
- ادخل إلى https://vercel.com وقم بإنشاء حساب (يمكنك التسجيل بحساب GitHub أو Google أو البريد).
- اختر خطة Hobby المجانية (كافية تماماً لهذا المشروع).

## الخطوة 3 — رفع المشروع (ثلاث طرق)
### الطريقة أ: من لوحة Vercel (الأسهل للملفات الجاهزة)
1. من لوحة التحكم اضغط **Add New → Project**.
2. اختر **Import** مع خيار رفع مجلد مباشرةً.
3. اسحب مجلد `pacc-dashboard` (أو ملفاته) وارفعه.
4. أثناء إعداد المشروع: اختر **Other** كإطار عمل، واترك حقل Command فارغاً (لا يوجد بناء).
5. اضغط **Deploy**.

### الطريقة ب: عبر استيراد من Git (إن كان المشروع في مستودع)
1. ارفع الملفات إلى مستودع GitHub/GitLab.
2. في Vercel: **Add New → Project → Import** واختر المستودع.
3. Vercel سيكتشف تلقائياً أنه مشروع ثابت **Static** (يظهر إطار العمل "Other").
4. اضغط **Deploy**.

### الطريقة ج: عبر سطر الأوامر (إن كانت الأدوات مثبتة)
```
npm i -g vercel
vercel login
cd pacc-dashboard
vercel --prod
```
اتبع التعليمات؛ سيُسأل عن إطار العمل فاختر **Other** إن ظهر السؤال.

## الخطوة 4 — ضبط الإعدادات
- المشروع ثابت لا يحتاج أي متغيرات بيئة أو أوامر بناء.
- ملف `vercel.json` المرفق يضمن:
  - معالجة العناوين بدون امتداد (`chairman` بدل `chairman.html`).
  - منع تخزين ملفي البيانات (تُفاتح دائماً بأحدث نسخة).
  - ترويسات أمان: `nosniff` ،`X-Frame-Options: DENY` ،`Referrer-Policy: no-referrer`.

## الخطوة 5 — النشر والتحقق
1. بعد انتهاء النشر يظهر رابط من الشكل `https://اسم-المشروع.vercel.app`.
2. افتح الرابط وتحقق من:
   - صفحة الدخول تعمل وتسجيل الخروج صحيح.
   - لوحة الرئيس تظهر 10 محاور و31 مؤشراً (اسم + سهم اتجاه فقط: أخضر للصعود وأحمر للهبوط)، ولوحة «التوصيات» الجانبية بجانب المؤشرات تحت صف مؤشرات KPI (السطر الأول كحلي والثاني ذهبي) وتُظهر التوصيات الـ33 بأسلوب الأخبار، والنقر على أي مؤشر يفتح نافذة «ماذا يقيس هذا المؤشر؟» + رسم بياني خطي عبر السنوات + زر «الجدول الكامل».
   - لوحة النائب تظهر القمع (9 مراحل) ونقاط الانتباه والجاهزية (جرّب على مقاسات 1920/1366/768/390).
   - تحديث الصفحة (F5) يحافظ على السنة والمقياس المختارين عبر `#year=2025&scale=…`.

## بيانات الدخول المؤقتة (سارية حتى تُستبدل)
- **رئيس الهيئة**: اسم المستخدم `chairman` — كلمة المرور `gFK%aZgtb5*zAf`
  (يدخل لوحة الرئيس ولوحة النائب معاً)
- **نائب الرئيس**: اسم المستخدم `deputy` — كلمة المرور `eU*kX3D&J2TF*w`
  (يدخل لوحة النائب فقط)
- **مدير النظام**: اسم المستخدم `admin` — كلمة المرور `123456`
  (يدخل لوحة الرئيس ولوحة النائب معاً — غيّر كلمة المرور فوراً لأنها ضعيفة)

> ملاحظة أمان: هذه كلمات مرور مؤقتة للبدء. لتغييرها استخدم `tools/hash.html` لتوليد مِلح وهاش جديدين لكل مستخدم ثم حدّث `js/users.js`، وأخبر المستخدمين وفّر الاتصالات الآمنة. هذا النظام واجهة عرض ثابتة بلا خادم؛ الحماية المعتمدة هي صلاحية الدور (رئيس/نائب) فقط.

## ملاحظات إضافية
- لا تعدّل الأرقام في `data.json` — الوثيقة المرجعية `README.md` هي المصدر الوحيد للأرقام والنصوص.
- إضافة توصية جديدة تتم بإضافة عنصر إلى `recommendations.json` (بمعرّف فريد `id` و`sortOrder`) دون تعديل الكود.
